# Furniture Store App

The **Furniture Store App** is a sleek Flutter-powered e-commerce masterpiece that brings premium furniture shopping to your fingertips. Browse curated collections by category, dive into rich product details with stunning visuals, and seamlessly add favorites to your cart for a mock checkout experience.

Built with **Dart**, **Firebase**, and state-of-the-art **Provider architecture**, this cross-platform gem delivers buttery-smooth performance, real-time sync, and a luxurious UI that feels like a high-end showroom on mobile. From cozy sofas to statement pieces, discover, dream, and design—your perfect home starts here.

> *This isn't just shopping—it's interior inspiration in motion, blending luxury design with cutting-edge mobile tech to redefine how you furnish your world.*

---

## ✨ Key Features

| Feature | Description |
|--------------------------|-----------------------------------------------------------------------------|
| **Rich Product Gallery** | High-res images, detailed descriptions, dimensions, materials, and pricing—presented in immersive card layouts. |
| **Smart Category Navigation** | Filter and browse by room (living, bedroom, office), style (modern, vintage), or type—making discovery intuitive and fun. |
| **Seamless Cart Management** | Add/remove items with live quantity updates, instant subtotal calculations, and persistent cart state across sessions. |
| **Mock Checkout Flow** | Experience a full purchase journey—from order summary to confirmation—with realistic steps (payment simulated for demo). |
| **Real-Time Firebase Sync** | Product data and user auth powered by Firestore and Firebase Authentication—ensuring fast, secure, and always-updated content. |
| **Fluid Animations & Responsiveness** | Hero transitions, micro-interactions, and adaptive layouts that shine on phones and tablets alike. |
| **Provider-Powered State Management** | Clean, efficient reactivity with Provider/Bloc for snappy UI updates without complexity. |
| **Secure User Experience** | Optional login via email or Google, with personalized wishlists and order history (expandable in production). |

## 🛠️ Installation

### Prerequisites
- **Flutter SDK**: Version 3.19 or later
- **Dart**: Version 3.3 or higher
- **Development Environment**: Android Studio or VS Code
- **Firebase Project**: Required for Firestore and Authentication

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/ramzy-ahmed/Furniture-Store-App.git
   ```
2. Open the project in Android Studio or VS Code.
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Configure Firebase:
   - Add `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)
   - Enable Firestore and Authentication in Firebase Console
5. Run the app:
   ```bash
   flutter run
   ```

> **Note**: Ensure Firebase is properly set up for real-time data and authentication to work.

## 🚀 Usage

Get started in seconds:
1. **Launch the App**: Explore categories or use search.
2. **Browse Products**: Tap any item to view full details, images, and specs.
3. **Add to Cart**: Adjust quantity and see live total updates.
4. **Proceed to Checkout**: Review order, simulate payment, and get confirmation.
5. **Login (Optional)**: Use email or Google sign-in to save wishlist and history.

**Advanced Tip**: Use Firebase Emulators for local testing without affecting production data.
